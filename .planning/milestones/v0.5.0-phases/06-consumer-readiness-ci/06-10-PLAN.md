<interfaces>
GitHub facts (RESEARCH Pitfall 6 and "Don't Hand-Roll"): `main` is unprotected today
(`gh api repos/AndrewRahman/SpatialCore/branches/main/protection` returns 404 "Branch not
protected"). Required status checks are identified by job name; a skipped job counts as passing.
They apply to direct pushes too, and by default administrators bypass them; `enforce_admins: true`
removes that bypass, so the owner's direct pushes of an unchecked commit are then refused. Classic
protection is set with one `gh api -X PUT repos/AndrewRahman/SpatialCore/branches/main/protection`
call whose JSON body has `required_status_checks` (`strict`, `checks: [{ "context": ... }]`),
`enforce_admins`, `required_pull_request_reviews` (null), `restrictions` (null); it is removed with
`gh api -X DELETE repos/AndrewRahman/SpatialCore/branches/main/protection`.

The user's documented push flow (memory `spatialcore-ship-and-verify-flow.md`): fetch; if
`origin/main` is an ancestor, push `HEAD:gsd-remap` and `HEAD:main`; other sessions (OpenSpatialPanner
work) also push to main, so merge `origin/main` first when it has moved. This worktree's branch is the
conductor branch the work was done on.

Scheduled workflows run only from the default branch and are disabled after 60 days without
repository activity (RESEARCH Pitfall 8).
