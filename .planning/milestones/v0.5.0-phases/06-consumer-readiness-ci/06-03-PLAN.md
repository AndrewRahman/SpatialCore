Build Release, run the named test, record the failing line (or exit code), then `git checkout -- <file>` and rebuild before anything else. - **Style:** each test file's existing style; cite the full tracker name (`Spatial-Media-Lab/OpenSpatialDelay#N`) in a comment above each new case (Phase 1 API-05 rule).
