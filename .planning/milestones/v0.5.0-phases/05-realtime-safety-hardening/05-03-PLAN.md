## Ground rules for this plan

- **The user is not a programmer.** Claude runs everything. The only reason to stop is D-10 (see Task 2).
- **Diff base:** `BASE` = HEAD when this plan started (record it in the SUMMARY).
- **One plan at a time** (shared `build/` and `build-release/`, both from Plan 05-01).
- **Full gates build every target** before running both executables or `ctest`.
- **Catch2 v3** exits non-zero on a failure or "No test cases matched"; a run of only skipped cases exits 4.
- **Trap discipline:** every input buffer is filled and every message-side call (`setHRTFProfile`, `waitForHRTFProfileIdle`, `setOutputFormat`, `setAlgorithmIndex`, `TrajectoryEngine::tick`, legacy loads and swaps, `getHRTFProfileStatus`) is made while disarmed; only `renderBlock` (and `getBlockLayout` read right after it on the same thread) runs armed. Every case calls `requireRealtimeTrapCanary()` first. Every cold-start combination is a fresh heap engine armed from its first block; the format and profile dimensions use one TEST_CASE per value so ctest runs each in a cold process.
- **Expected Debug noise:** "Leaked objects detected: 1 FFT" at exit (D-08), libmysofa `/Users/` trace lines.
- **Time budget:** the Release run of `[rt]` should stay within a few minutes; if the Debug run of `[matrix]` exceeds about 5 minutes, reduce blocks per combination from 120 to 60 for the algorithm and size dimensions only (never for the cold-start format and profile cases) and record that in the SUMMARY.
