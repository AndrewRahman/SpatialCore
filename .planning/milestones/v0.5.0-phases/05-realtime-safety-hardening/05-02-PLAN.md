JUCE logs and only breaks under a debugger; the Debug run does not stop (RESEARCH Pitfall 9, precedent `tests/Engine/RenderEngineTests.cpp:1630`).

- **Style:** as `tests/Engine/RenderEngineTests.cpp`; library code keeps the existing comment density and JUCE spacing.
- **DR-1:** inside `renderBlock` nothing may allocate, lock or log; a `RenderSources` copy on the stack is allowed (fixed arrays, no heap).
