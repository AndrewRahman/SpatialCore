<objective>
Make playback impossible to crash, hang, or poison from a position value, in both layers a consumer
can enter through, and verify the lower-hemisphere construction from Plan 02-01 against its
independent oracle.

Purpose: D-06's stance — "a position can never crash because a user or a network peer can cause
it" — extended by D-19 to both layers, because OpenSpatialDelay calls `algo->computeGains` itself
and never passes through `RenderEngine`'s gain path (RESEARCH F7). Today `computeVBAPGains2D` hangs
forever on `+inf` or any azimuth of about 1e9 radians, KNN returns NaN gains for NaN input, the ADM-
OSC receiver forwards NaN as a "field not set" sentinel with no clamp, and a NaN distance poisons
`smoothedNfcDistance` for good. Task 3 then proves D-04 against PyPI `ear` 2.1.0 and proves every
finite direction finds a triplet, which is what makes the D-06b fallback a safety net rather than a
code path.

Output: algorithm-layer guards and the D-06b fallback in `SpatialMath.cpp`, KNN and DirectBinaural
guards, the engine's hold-last-good sanitiser, and the `[robust]`, `[sanitize]` and `[ear]` tests.
</objective>
