- **Style:** `tests/Engine/RenderEngineTests.cpp` style; library code in JUCE spacing; no new public type.
- **Detection rule (Claude's discretion, D-05):** count a block when (1) the consumer's engineComputesGains is false, (2) the finished context selects a gain-reading path, (3) at least one object is active, and (4) every active object's gains on that path are exactly 0. Rationale: this is precisely "gains neither computed nor supplied" (INTG-02's acceptance wording); a consumer that supplies gains for any object has chosen the supplied mode, and one deliberately silent object is legitimate. Active = `objectLive[t]` and non-null `monoBuffers[t]` and `tapFadeGainPerSample[t]` and the tap fade above 0 at the block's first or last sample (the paths skip samples whose fade is 0 or less).
