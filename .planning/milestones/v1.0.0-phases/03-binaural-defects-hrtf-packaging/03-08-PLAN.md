## Ground rules for this plan

- **Diff base:** `BASE` = the commit HEAD pointed at when this plan started (record it in the SUMMARY).
- **The user is not a programmer.** Claude runs every build and test. The one question (Task 2) is a
  plain-English choice about a table of numbers.
- **One plan at a time** (Plan 03-01 ground rules): this plan runs after Plan 03-07 has committed
  and before Plan 03-09, never alongside another plan.
- **Measure in a disposable copy; the main tree's pin moves only after the user decides.** Task 1
  never edits the main tree's `CMakeLists.txt` and never reconfigures `build/`, so every Task 2
  option starts from the same v1.3.2 tree and nothing has to be undone. Measurement uses a detached
  worktree `/tmp/sc-mysofa135-src` (created with
  `git worktree add --detach /tmp/sc-mysofa135-src HEAD`, removed with `git worktree remove --force`)
  and build trees `/tmp/sc-mysofa135-dbg` / `/tmp/sc-mysofa135-rel`, configured with
  `-DFETCHCONTENT_SOURCE_DIR_JUCE="$PWD/build/_deps/juce-src" -DFETCHCONTENT_SOURCE_DIR_CATCH2="$PWD/build/_deps/catch2-src"`
  and **without** a mysofa source override, so FetchContent downloads v1.3.5 (network). The
  "before" values come from the main `build/` and `build-release/` (v1.3.2).
- **Network precondition:** `git ls-remote --tags https://github.com/hoene/libmysofa.git v1.3.5` must
  print `6cc5b15a73e9bd97810d03767082edda7f315881`.
- **What counts as "moved":** any of these tags failing under v1.3.5 where it passes under v1.3.2:
  `[binaural]` (sync-load IR lengths and positions, golden fingerprints, SADIE/KEMAR delay checks),
  `[renderer][itd-characterisation]`, `[hrtf-embed]`, `[hrtf-resolve]`. `[loudness]` numbers are
  recorded, never asserted (D-14), and reported in the table either way.
- **Reversibility:** the pin is `costly` (consumers that fetch libmysofa through SpatialCore,
  including OSD's build, get the new parser). The golden re-baseline is gated by the user.
