## Ground rules for this plan

- **The user is not a programmer.** Claude runs everything; nothing is asked.
- **Diff base:** `BASE` = the commit HEAD pointed at when this plan started (record it in the SUMMARY).
- **Build trees and commands** as in Plan 03-01.
- **One plan at a time** (Plan 03-01 ground rules): this plan runs after Plan 03-06 has committed and
  before Plan 03-08, never alongside another plan.
- **ThreadSanitizer tree** (Task 2) lives in `/tmp`, outside the repository:
  `cmake -S . -B /tmp/sc-tsan -DCMAKE_BUILD_TYPE=Debug -DCMAKE_C_FLAGS=-fsanitize=thread -DCMAKE_CXX_FLAGS=-fsanitize=thread -DCMAKE_EXE_LINKER_FLAGS=-fsanitize=thread -DFETCHCONTENT_FULLY_DISCONNECTED=ON -DFETCHCONTENT_SOURCE_DIR_JUCE="$PWD/build/_deps/juce-src" -DFETCHCONTENT_SOURCE_DIR_CATCH2="$PWD/build/_deps/catch2-src" -DFETCHCONTENT_SOURCE_DIR_MYSOFA="$PWD/build/_deps/mysofa-src"`,
  then `cmake --build /tmp/sc-tsan --target SpatialCoreTests -j8` (a first build compiles JUCE:
  several minutes; run it in the background or with a 10-minute timeout).
- **Do not edit** `tests/CMakeLists.txt` or `tests/Binaural/BinauralMetrics.h`. Test-local helpers
  go in `ProfileSwitchTests.cpp`'s anonymous namespace.
- **Why a watchdog aborts:** a `std::future` returned by `std::async` blocks in its destructor until
  the task finishes, so a plain `wait_for` timeout would still hang on a deadlock. The watchdog
  prints a named message to stderr and calls `std::abort()`, which makes the test binary exit
  non-zero.
- **What Plan 03-06 left:** `setHRTFProfile`, `getHRTFProfileStatus`, `waitForHRTFProfileIdle`,
  `setSharedHRTFFolderForTesting`, the `HRTFProfileLoader` worker, the `readyRenderer_` mailbox, the
  `rendererFree_` flags, `claimReadyRenderer`, and the test-local helpers `renderUntilActive` and the
  temp-folder fixture in `ProfileSwitchTests.cpp`.
