<objective>
Make the HRTF data handover provably safe without changing a sample or breaking
OpenSpatialDelay. The safe route (`setHRTFProfile`) is proven race-free under the scenario ROADMAP
criterion 3 names (a UI timer switching profiles while audio renders). The legacy route OSD calls
today stays exactly as it is, gets a written thread contract, and gets two lock-free detectors: one
for a legacy call made on the render thread, one for a load into a renderer the audio thread is
using (RESEARCH F5: lookups write a scratch buffer inside the libmysofa handle, so the damage is
wider than `easyHandle` and `loaded`).

Purpose: RTSF-03 under D-09 and D-10.

Output: `getLegacyRouteWrongThreadCount()`, the `HRTFDatabase` in-use API, the engine's in-use
marking, the contract comments and four `[hrtf-switch]` tests.
</objective>
