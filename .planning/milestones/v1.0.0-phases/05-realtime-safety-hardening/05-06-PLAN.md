- **Engines on the heap** (`std::make_unique<RenderEngine>()`): a `std::thread` has a small stack and the engine is large. Call `waitForHRTFProfileIdle` before destroying an engine that was asked for a profile (the destructor's 15 s stopThread must never expire, Pitfall 4).
- **D-07 mutations** happen only after the task's implementation is committed, in a scratch step, each run under a watchdog (a mutated cache can spin forever, Pitfall 6), and are restored with `git checkout -- <file>` and a rebuild; record each in the SUMMARY.
- **Full gates build every target** before running both executables or `ctest`.
