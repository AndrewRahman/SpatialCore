## Ground rules for this plan

- **The user is not a programmer.** Claude builds and runs the demo and looks at the images; the user
  only approves the screenshots in plain language at the end-of-phase review.
- **Diff base:** `BASE` = the commit HEAD pointed at when this plan started (record it in the SUMMARY).
- **One plan at a time.** Phase 4 runs serially; this plan starts from the tree Plan 04-06 committed.
- **Demo build tree:** `build/demo` (inside the gitignored `build/`, so no `.gitignore` change), Debug,
  configured with `-DSPATIALCORE_BUILD_EXAMPLES=ON -DSPATIALCORE_BUILD_TESTS=OFF` and the same offline
  dependency sources as `build/` (Plan 04-01 ground rules: `DEPS=/private/tmp/sc-kemar-only-validate/_deps`
  if `$DEPS/juce-src/CMakeLists.txt` exists, else `DEPS="$PWD/build/_deps"`, with the three
  `FETCHCONTENT_SOURCE_DIR_*` overrides and `FETCHCONTENT_FULLY_DISCONNECTED=ON`). The binary is found with
  `find build/demo/examples -type f -name SpatialCoreDemo -perm -u+x | head -1` (on macOS it is inside
  `SpatialCoreDemo_artefacts/Debug/SpatialCoreDemo.app/Contents/MacOS/`). The default `build/` keeps the
  option OFF.
- **Screenshots** go to `.context/sc-shots/` (gitignored), as `04-VALIDATION.md` specifies.
- **Headless rules:** in `--screenshots` and `--selftest` modes the app opens no window and no audio
  device; it renders with `createComponentSnapshot` (RESEARCH Pattern 7, verified: 480x480 PNG in about
  1 s). Only interactive mode opens a window and the default audio device.
- **Threads (DR-1):** message thread writes positions into per-object `std::atomic<float>` / `std::atomic<bool>`;
  the audio callback only loads them and calls `RenderEngine::renderBlock` on buffers sized before audio
  starts. No lock, allocation, logging or `TrajectoryEngine` read on the audio thread (that cross-thread
  read is RTSF-02, Phase 5; the demo avoids it by copying through atomics).
- **Ports:** interactive defaults receive 4002 and send 127.0.0.1:4003 (project convention,
  `adm-osc-integration.md:200`), overridable with `--osc-in <port>` and `--osc-out <port>`, checked with
  `oscPortsConflict` before connecting; the self-test uses 9790 (receive) and 9791 (send) only.
- **Expected Debug noise:** JUCE leak-detector lines at exit; they do not change the exit code.
