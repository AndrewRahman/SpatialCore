<objective>
Stand up the third build tree D-01 asks for (optimised, with ThreadSanitizer) and use it, end to
end, on the race SpatialCore#18 names: the trajectory positions a timer thread writes as plain
floats while another thread reads them.

join a `[tsan]` subset so the sanitizer gate is one command, and the size of a "mixed" reading
(azimuth from one tick, elevation from the next) is measured and pinned.
