<objective>
Neutralise every remaining document that states stale facts in the present tense, without
creating a second source of truth to maintain (D-01 Tier B, D-03).

Purpose: D-03 is the general rule that settles this plan — **documents state current reality;
future or past state is permitted but must be explicitly labelled as such.** Aspirational or
expired content presented as present-tense fact is the defect class this phase exists to
eliminate. Tier B documents are dated snapshots, so the correct treatment is a stamp, not a
renumbering: renumbering them would commit the project to maintaining them forever, which is how
the drift started.

The same reasoning applies to the project's own planning documents, which carry factual errors
discovered during this phase's discussion and research. They mis-steer planning by exactly the
mechanism `CLAUDE.md` did — the phase's stated target — so they are corrected here.

Output: three stamped Tier B locations, and two corrected planning documents.
</objective>
