## Ground rules for this plan

- **The user is not a programmer.** Claude runs every configure, build and test. Nothing here needs a decision from the user.
- **Diff base:** `BASE` = the commit HEAD points at when this plan starts (record it in the SUMMARY).
- **One plan at a time.** Phase 6 runs serially, one plan per wave: every plan builds in the shared `build/` and `build-release/` trees (and from Plan 06-07 also `build-cov/`).
- **Build trees.** This worktree has none yet and no shared dependency cache exists (the old `/private/tmp/sc-kemar-only-validate/_deps` is gone). Task 1 configures `build/` first with no overrides (it downloads JUCE 9.0.0, Catch2 v3.7.1 and libmysofa v1.3.5 into `build/_deps`), then `build-release/` with `-DFETCHCONTENT_FULLY_DISCONNECTED=ON -DFETCHCONTENT_SOURCE_DIR_JUCE=$PWD/build/_deps/juce-src -DFETCHCONTENT_SOURCE_DIR_CATCH2=$PWD/build/_deps/catch2-src -DFETCHCONTENT_SOURCE_DIR_MYSOFA=$PWD/build/_deps/mysofa-src` (check the three directory names with `ls build/_deps` first). Write flags out in full (zsh does not word-split a variable holding several flags). Debug adds `-DCMAKE_BUILD_TYPE=Debug -DCMAKE_EXPORT_COMPILE_COMMANDS=ON`; Release adds `-DCMAKE_BUILD_TYPE=Release`. Later plans reuse both trees.
- **Full gates build every target** before running either executable or `ctest`; an unbuilt Catch2 target registers a failing `_NOT_BUILT` test.
- **Catch2 v3** exits non-zero on a failed assertion and on "No test cases matched"; a run in which every selected case SKIPs exits 4.
- **Expected Debug noise, not failures:** "Leaked objects detected: 1 FFT" at exit (the process-lifetime SharedFFTCache), JUCE assertion log lines from deliberate-misuse tests, libmysofa trace lines starting with `/Users/`. Key every verdict on exit codes.
- **The full Debug `SpatialCoreTests` run can exceed 20 minutes.** Run it in the background with at least 30 minutes, with its whole output captured to a file (`> /tmp/sc-p6-01-debug.log 2>&1; echo "exit=$?" >> /tmp/sc-p6-01-debug.log`), and read the recorded exit status.
- **CRLF:** `tests/CMakeLists.txt` is CRLF in the index. Edit it only with the Edit tool on exact lines, then check `git diff --stat tests/CMakeLists.txt` shows only the added lines and `git ls-files --eol tests/CMakeLists.txt` still reports `w/crlf`. New files are LF.
- **Style:** as `tests/Core/CountsTests.cpp`: JUCE spacing (`f (x)`), 4-space indent, file-local helpers in an anonymous namespace, `using namespace spatialcore;`.
