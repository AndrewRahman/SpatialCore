## Ground rules for this plan

<!-- planner-discipline-allow: WARNING: ThreadSanitizer -->

- **The user is not a programmer.** Claude writes the workflow, pushes, starts and watches runs (`gh run list`, `gh run view`, `gh run watch`), reads logs and fixes failures. Nothing here needs a decision.
- **Outward actions (only these):** `git push origin HEAD` of the current work branch, and `gh workflow run ci.yml --ref <branch> -f realtime=...` dispatches. Never push to `main`, never force-push, never change repository settings.
- **Repository:** `AndrewRahman/SpatialCore` (pass `-R AndrewRahman/SpatialCore` to `gh`). Never `Spatial-Media-Lab/SpatialCore`.
- **Waiting on runs:** a gate run takes tens of minutes and the realtime run about two to three hours. Watch in the background (`gh run watch <id> -R AndrewRahman/SpatialCore --exit-status`, background timeout up to 2 h, re-attach if needed) or poll `gh run view <id> --json status,conclusion,jobs`. Always identify the run by its `headSha` equal to `git rev-parse HEAD`.
- **On a red run:** `gh run view <id> --log-failed`, fix the cause (in the workflow, or in code with a test if it is a real defect that also shows locally), commit, push, and re-run. A failure caused by the runner being slower is fixed by timeouts or `SPATIALCORE_TEST_TIMEOUT_SCALE`, never by weakening a test. Record every red run and its fix in the SUMMARY.
- **The workflow file is LF.** YAML strings that hold shell use `run: |` blocks with `set -euo pipefail` as the first line; every value from a `${{ }}` expression enters a script only through an `env:` entry.
- **Diff base:** `BASE` = HEAD at plan start.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pull request code → GitHub Actions runner | Code from a pull request runs in CI. |
| workflow expressions → shell | Branch names and SHAs are attacker-influenced strings. |
| third-party action code → runner | Each `uses:` runs someone else's code with the job's token. |
| cache → build | A restored cache feeds data into the build. |

## STRIDE Threat Register

| T-06-12 | Elevation of privilege | workflow token | high | mitigate | `permissions: contents: read` at the top level; no job raises it. |
